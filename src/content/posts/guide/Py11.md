# 电影榜单爬虫项目 - 新手向代码解析

## 📌 项目目标

从 TMDB（The Movie Database）网站抓取**评分最高的电影榜单**（前5页，约100部电影），并将每部电影的详细信息保存到 CSV 文件中。

---

## 🧠 整体思路（一句话概括）

> **发请求 → 解析HTML → 提取数据 → 清洗数据 → 保存到CSV**

---

## 📁 代码结构总览

```
电影榜单爬虫
│
├── 1️⃣ 导入工具库
│   ├── requests → 发送网络请求
│   ├── lxml → 解析HTML（XPath定位）
│   ├── csv → 保存数据到文件
│   └── re → 正则表达式（清洗数据）
│
├── 2️⃣ 定义常量（固定不变的配置）
│   ├── 请求头（模拟浏览器）
│   ├── 文件保存路径
│   └── 目标网址
│
├── 3️⃣ 数据清洗函数（处理原始数据）
│   ├── get_movie_year() → 去掉年份的括号
│   ├── get_movie_publish_date() → 提取日期格式
│   └── get_movie_cost_time() → 时长转分钟
│
├── 4️⃣ 获取电影详情函数
│   ├── 发送请求到详情页
│   ├── 用XPath提取11个字段
│   ├── 调用清洗函数处理数据
│   └── 返回字典格式的电影信息
│
├── 5️⃣ 保存数据函数
│   └── 将电影列表写入CSV文件
│
└── 6️⃣ 主函数（核心流程）
    ├── 循环5次（爬5页）
    ├── 第1页用GET请求，其他页用POST
    ├── 解析每页的电影列表
    ├── 遍历每部电影，获取详情
    ├── 收集到 all_movies 列表
    └── 最后保存到CSV
```

## 🔧 各模块详细解读

### 1️⃣ 导入工具库

```python
import re          # 正则表达式，用于从文本中提取/清洗特定格式
import requests    # 发送HTTP请求，获取网页内容
import csv         # 操作CSV文件（保存数据）
from lxml import html  # 将HTML字符串转成可XPath查询的对象
```

| 库名 | 作用 | 新手理解 |
|------|------|----------|
| `requests` | 向网站要数据 | 就像在浏览器输入网址，获取网页源代码 |
| `lxml` | 从HTML中找数据 | 在一堆标签里用XPath精准定位内容 |
| `csv` | 保存数据 | 把数据存成Excel能打开的表格文件 |
| `re` | 清洗数据 | 从"乱七八糟"的文本中提取干净内容 |

### 3️⃣ 数据清洗函数

#### 清洗年份 - `get_movie_year()`

```python
def get_movie_year(movie_years):
    movie_year = movie_years[0].strip() if movie_years else ""
    return movie_year.replace("(", "").replace(")", "")
```

| 输入 | 输出 |
|------|------|
| `["(2023)"]` | `"2023"` |
| `[]`（没有数据） | `""` |

#### 清洗上映时间 - `get_movie_publish_date()`

```python
def get_movie_publish_date(movie_times):
    movie_time = movie_times[0].strip() if movie_times else ""
    c = re.search(r"\d{4}-\d{2}-\d{2}", movie_time)  # 找日期格式
    return c.group() if c else ""
```

| 输入 | 输出 |
|------|------|
| `["2023-01-15 (US)"]` | `"2023-01-15"` |
| `["No info"]` | `""` |

#### 清洗时长 - `get_movie_cost_time()`

```python
def get_movie_cost_time(movie_cost_times):
    movie_cost_time = movie_cost_times[0].strip() if movie_cost_times else ""
    h_res = re.search(r"(\d+)h", movie_cost_time)  # 找小时
    m_res = re.search(r"(\d+)m", movie_cost_time)  # 找分钟
    h = int(h_res.group(1)) if h_res else 0
    m = int(m_res.group(1)) if m_res else 0
    return h * 60 + m  # 全部换算成分钟
```

| 输入 | 输出 |
|------|------|
| `["2h 30m"]` | `150`（分钟） |
| `["45m"]` | `45` |
| `["1h"]` | `60` |

### 4️⃣ 获取电影详情 - `get_movie_info()`

**核心逻辑：**
1. 发送请求到详情页URL
2. 用XPath提取11个字段
3. 调用清洗函数处理特殊字段
4. 返回字典

**提取的字段：**

| 字段名 | XPath目标 | 清洗方式 |
|--------|-----------|----------|
| 电影名 | `//*[@id="original_header"]/.../h2/a/text()` | 直接strip |
| 年份 | 同区域span标签 | `get_movie_year()`去括号 |
| 上映时间 | class="release" | `get_movie_publish_date()`提取日期 |
| 类型 | class="genres"下的a标签 | 用逗号连接多个类型 |
| 时长 | class="runtime" | `get_movie_cost_time()`转分钟 |
| 评分 | `@data-percent`属性 | 直接strip |
| 语言 | `//section[@class="facts left_column"]/p[3]` | 直接strip |
| 导演 | 第一个li下的a标签 | 可能多个导演，用逗号连接 |
| 小说作者 | 第二个li下的a标签 | 可能多个作者，用逗号连接 |
| 宣传语 | class="tagline" | 直接strip |
| 简介 | `//.../div/p/text()` | 直接strip |

> 💡 **关于XPath**：这些XPath是通过浏览器的"开发者工具"（F12 → 检查元素）找到的，不同网站结构不同，需要针对性调整。

## 🎯 新手常见问题

### Q1: 为什么第1页用GET，其他页用POST？
**A:** 这是TMDB网站的设计：
- 第1页是普通网页，浏览器输入网址就能看
- 下滑加载更多时，网站通过POST请求获取数据（前后端分离）

### Q2: XPath路径是怎么找到的？
**A:** 
1. 在浏览器中打开目标网页
2. 按F12打开开发者工具
3. 点击"检查"（或审查元素）
4. 点击网页上的内容，查看对应的HTML标签
5. 右键 → Copy → Copy XPath

### Q3: 运行时会不会被封IP？
**A:** 代码中设置了：
- `timeout=60`（超时时间）
- `headers`（模拟浏览器）
- 爬取5页共100部电影，数量不大，一般安全

### Q4: 为什么有时会报错？
**A:** 常见原因：
- 网站改版（XPath失效）
- 网络连接问题
- 请求被反爬（需要更换headers或加延时）

## `["No info"]` 是什么？

### 简单回答

`["No info"]` 是一个**列表**，里面包含一个字符串 `"No info"`，意思是 **"没有信息"**。

---

### 详细解释

在爬虫代码中，当你用 XPath 提取网页元素时：

```python
movie_times = movie_doc.xpath('.../span[@class="release"]/text()')
```

- 如果网页上**有**这个元素，`movie_times` 可能是 `["2023-01-15 (US)"]`
- 如果网页上**没有**这个元素，XPath 会返回空列表 `[]`

但是有些网站会**故意放一个占位符**，比如 `"No info"`，表示"这个字段暂时没有数据"。

所以 `["No info"]` 就是网站告诉你：**"这个电影的上映时间，我这里没有记录"**。

---

### 在代码中如何处理？

在 `get_movie_publish_date()` 函数中：

```python
def get_movie_publish_date(movie_times):
    movie_time = movie_times[0].strip() if movie_times else ""
    #    ↑ 取列表第一个元素         ↑ 如果列表不为空才取
```

**各种情况对比：**

| `movie_times` 的值 | `movie_time` 的值 | 正则匹配结果 | 最终返回 |
|-------------------|-------------------|--------------|----------|
| `["2023-01-15 (US)"]` | `"2023-01-15 (US)"` | `"2023-01-15"` | `"2023-01-15"` |
| `["No info"]` | `"No info"` | 找不到日期格式 | `""`（空字符串） |
| `[]`（空列表） | `""`（空字符串） | 找不到日期格式 | `""`（空字符串） |

---

### 通俗理解

就像你填表格时：

- **有数据**：`"1994-09-23"` ✅
- **没数据，留空**：`""`（空字符串）
- **没数据，但写了备注**：`"暂缺"` / `"No info"` / `"无"`

`"No info"` 就是网站写的**备注**，表示"我这里没有这个信息"。

最后清洗函数会把这种"备注"处理成干净的空字符串 `""`，让 CSV 表格里显示为空白单元格。
