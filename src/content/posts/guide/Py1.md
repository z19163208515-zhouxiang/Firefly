## 字面量

程序中，直接书写的固定值（数据）。

| 字面量类型 | 以及 | 书写格式 |
|------------|------|----------|
| 数字类型 | 整数 | 10, 18, -5, 0 |
| 数字类型 | 浮点数/小数(float) | 8.5, 3.14, 1.0, -3.5 |
| 布尔(bool) | 表达现实中的逻辑，真或假 | True, False |
| 字符串(str) | 描述文本的一种数据类型 | "人生苦短及时行乐" |
| 空值(NoneType) | 表达空或无值，仅包含一个值None | None |
| 数据容器 | 存储多项数据的容器 | 列表、元组、集合、字典 |

> 布尔类型本质就是数字类型，在涉及到数学运算时，会自动将True转为1，False转为0。

```python
print(100)           # 整数
print(3.14)          # 浮点数/小数(float)
print(True)          # 布尔(bool)
print(False)         # 布尔(bool)
print("hello python") # 字符串(str)
print(None)          # 空值(NoneType)
print(True + 1)      # 布尔本质也是整数类型
```

## 变量

程序中用来存储单个数据的容器，通常会把经常发生变化的数据存储在变量中。

> 变量是指存储数据的容器（空间），而不是容器里面存储的数据。

### 定义格式

`变量名 = 变量值`

- **变量值**：每一个变量都有自己存储的值（数据）
- **赋值（=）**：表示将等号右边的值，赋予左侧的变量
- **变量名**：每一个容器（空间）的名字

> Python是动态语言类型，在程序运行时才进行类型检测，变量的类型可以在程序运行过程中改变（一个变量可以接收不同类型的值）。**项目开发中，推荐变量只存储一种类型的值。**

```python
num = 1114.1
print(num)

num = num + 1
print(num)

num = "ok"
print(num)

num = True
print(num)

num = False
print(num)
```

```python
base = 20.7
incr = 50
print("未来一个月播放量", base + incr)
print("未来两个月播放量", base + incr + incr)

# 多变量赋值
base, incr = 20.7, 50
print("未来一个月播放量", base + incr)
print("未来两个月播放量", base + incr + incr)
```

是指程序员在代码中为变量、函数、类等元素所起的名字。

### 命名规则

1. 只能包含字母（a-z, A-Z）、数字（0-9）、下划线（_）

- 多个部分使用下划线
- 英文字母全小写

## 变量案例（变量交换）

### 两个变量交换

现有两个变量，分别为 `a = 10`，`b = 20`，现在需要将这两个变量值交换，输出到控制台。

```python
a = 10
b = 20
c = a    # 临时变量c
a = b
b = c
print(a, b)   # 输出 20 10
```

### 三个变量交换

现有三个变量，分别是 `a = 100`，`b = 200`，`c = 300`。现需要将这三个变量值进行交换，将a、b、c的值分别赋值给c、a、b，输出到控制台。

```python
# 方法1：使用临时变量
a = 100
b = 200
c = 300
temp1 = a
temp2 = b
temp3 = c
c = temp1
a = temp2
b = temp3
print(c)   # 100
print(a)   # 200
print(b)   # 300

# 方法2：使用元组解包
a, b, c = 100, 200, 300
a, b, c = b, c, a
print(c, a, b)
```

## 数据类型

| 标准名称 | 描述 | 说明 |
|----------|------|------|
| int | 整数 | 数字类型，存放整数，如10，-5 |
| float | 浮点数 | 数字类型，存放小数，如8.5，3.14，1.0，-3.5 |
| str | 字符串 | 用引号引起来的都是字符串，如"Python" |

### type() 获取数据类型

通过 `type()` 语句来得到数据的类型，具体语法为 `type(要查看类型的数据)`。

```python
print(type("hello"))
print(type(10))
print(type(3.14))

num = 5.0
print(num)
print(type(num))
```

> 变量本身是没有类型的，`type(变量)` 输出的类型是变量中存储的数据的类型。

### isinstance() 检查数据类型

通过 `isinstance()` 检查数据是否属于指定类型，返回的是一个bool值。语法：`isinstance(数据, 类型)`

```python
num = -100
print(isinstance(num, int))   # True
```

## 字符串拼接

很多时候，我们需要将多个字符串拼接起来，可以直接使用 `+` 进行拼接。

> `+` 号可以用来拼接两个字符串，但无法将非字符串与字符串进行拼接（非字符串需要转换为字符串类型）。

```python
#字符串字面量自动拼接（隐式拼接）
Slogan = "我是" "ZX"
Slogan = "我是" + "ZX"

s1 = "我是"
s2 = "ZX"
print("鲁迅:" + s1 + "," + s2)

# str(int数字) 将int类型数据转为字符串
name = "ZX"
age = 18
pro = "牛马"
hobby = "C++"
print("大家好，我是" + name + ",今年" + str(age) + "岁,学习的专业是" + pro + ",爱好是" + hobby)
```

## 字符串格式化

### 使用 `%` 占位符

通过 `%` 占位符的形式完成字符串和变量的快速拼接（其中 `%` 表示我要占位，`s` 表示将变量转为字符串放入占位符）。

```python
s1 = "ZX"
print("大家好,我是%s" % s1)

s1 = "ZX"
s2 = 18
print("大家好,我是%s,今年%s" % (s1, s2))
```

### 使用 `f-string`

通过 `f"内容{变量/表达式}"` 的形式来完成快速格式化。

```python
name = "ZX"
age = 20
print(f"大家好，我是{name},今年{age}岁了")
```

## 算术运算符

| 运算符 | 描述 | 举例说明 |
|--------|------|----------|
| `+` | 加法 | `1 + 5` |
| `-` | 减法 | `8 - 3` |
| `*` | 乘法 | `3 * 8` |
| `/` | 除法 | `10 / 5`（除法结果是小数） |
| `//` | 整除 | `10 // 3`（整除结果是整数） |
| `%` | 取余/求模 | `10 % 3` 结果为1（10除3取余数） |
| `**` | 幂指数 | `10 ** 3`（10的三次方） |

**优先级**：`()` → `**` → `*` `/` `//` `%` → `+` `-`（括号第一，幂第二，乘除取余排第三，加减最后从左到右）

```python
x = float(input())
y = float(input())
print("x + y = ", x + y)
print("x - y = ", x - y)
print("x * y = ", x * y)
```

### 浮点数精度问题


> 由于计算机底层是基于二进制来进行数据的存储和处理的，而二进制是无法精确表示所有的小数的，因此涉及到浮点数的运算时，可能损失精度。

## 赋值运算符

| 运算符 | 描述 | 实例 |
|--------|------|------|
| `=` | 赋值运算符 | 把 = 号右边的结果赋值给左边 |
| `+=` | 加法赋值运算符 | `num += 2` 等效于 `num = num + 2` |
| `-=` | 减法赋值运算符 | `num -= 2` 等效于 `num = num - 2` |
| `*=` | 乘法赋值运算符 | `num *= 2` 等效于 `num = num * 2` |
| `/=` | 除法赋值运算符 | `num /= 2` 等效于 `num = num / 2` |
| `%=` | 取模赋值运算符 | `num %= 2` 等效于 `num = num % 2` |
| `//=` | 取整除赋值运算符 | `num //= 2` 等效于 `num = num // 2` |
| `**=` | 幂赋值运算符 | `num **= 2` 等效于 `num = num ** 2` |

```python
num = 85
num += 10   # 95
num -= 10   # 85
num *= 10   # 850
num /= 10   # 85.0（除法运算是小数）
num //= 10  # 8.0
num %= 3    # 2.0
num **= 3   # 8.0
print("答案是%s" % num)
```

| `<` | 小于 | `a < b` |

## 逻辑运算符

逻辑运算符是用于连接多个条件（布尔）表达式（其值为真或假），并返回一个最终布尔结果的运算符。

| 运算符 | 描述 | 实例 |
|--------|------|------|
| `and` | 逻辑与（并且） | 同时成立才符合条件，左右两边都是True，结果才是True |
| `or` | 逻辑或（或者） | 只要有一个符合条件的即可，左右两边有一个True，结果就是True |
| `not` | 逻辑非（取反） | 取反操作，True变为False，False变为True |

```python
a < b and b < c
a < b or b < c
```

### 案例：判断数字是否在区间内

```python
# 键盘输入一个整数，判断是否在10到20之间
num = input("请输入一个数")
n = int(num)   # 或 n = int(input("请输入一个数"))
print("n在10到20之间:", n >= 10 and n <= 20)
print("n在10到20之间:", 10 <= n <= 20)   # 简化写法

# 键盘输入一个整数，判断这个数字是否不在10到20之间
n = int(input("请输入一个数"))
print(f"{n}不在10到20之间:", n < 10 or n > 20)   # 模板字符串
```


### 2. 常量与删除变量（补充“存储”概念）

- **`del` 关键字**：手动删除变量，释放其对数据的引用（配合内存回收理解）。

### 3. 逻辑运算符的“短路”特性（补充“运算”逻辑）
笔记只讲了 `and`/`or` 的真值表，但**短路求值**是 Python 独有的重要机制:

- `and`：如果左边为 `False`，右边**根本不执行**，直接返回左边值。
- `or`：如果左边为 `True`，右边**根本不执行**，直接返回左边值。
- **返回值**：逻辑运算符返回的不一定是 `True/False`，而是**最后一个被评估的操作数**。

```python
# 补充示例
a = 0 and 10   # 结果为 0 (0为False，短路，不评估10)
b = 5 or 0     # 结果为 5 (5为True，短路，不评估0)
c = [] and 10  # 结果为 [] (空列表为False)
print(a, b, c) 
```

### 5. `is` 与 `==` 的本质区别（补充“存储”核心）
初学者极易混淆这两个运算符，既然本笔记叫“数据存储”，这个知识点是绝佳的补充：

- **`==`**：比较**值**是否相等（内容）。
- **`is`**：比较**内存地址**是否相等（是否是同一个对象）。

```python
# 补充示例
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)  # True (值相同)
print(a is b)  # False (两个独立列表，内存地址不同)

c = a
print(a is c)  # True (指向同一个对象)
```
