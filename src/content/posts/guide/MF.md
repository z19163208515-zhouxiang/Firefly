# F2L 标态笔记

## F2L 标态
白前棱左 上颜不同 : 逆右顺

白右棱后 上颜不同 : 上左下

## F2L 白在前 角块与棱块颜色相同
白前棱后 上颜相同 : 右上左下(藏角 棱去接)

白前棱左 上颜相同 : 右上右右下(藏角 棱去接)

白前棱下 前颜相同 : 右上右下(藏角 棱去接)

白前棱左(紧挨) 上颜相同 : 上左下右右 上右下(记住)

## F2L 白在前 角块与棱块颜色不同(变为逆右顺标态)
白前棱后 上颜不同 : 右上右下(角藏后 棱放前)

白前棱左(紧挨) 上颜不同 : (确保右后方是空槽) 下左上(角藏前 棱放左)

白前棱后(紧挨) 上颜不同 : 右上右右下(角藏后 棱放前)

白前棱下 前颜不同 : 右上左下(角藏后 棱放前)

## F2L 白在右 角块与棱块颜色相同
白右棱下(紧挨) 前颜相同 : 右上右右下(角藏后 棱放左) -> 上左下标态

白右棱后(紧挨) 上颜相同 : 上右下右右(棱藏后 角块放左后方) -> 逆右顺标态

## F2L 白在右 角块与棱块颜色不同(变为上左下标态)
白右棱左 上颜不同 : 右上左下(角藏后 棱放左)

白右棱后(紧挨) 上颜不同 : 右上右下(角藏后 棱放左)

白右棱左(紧挨) 上颜不同 : (确保右后方是空槽) 下右右上(角藏前 棱放后)

白右棱下(紧挨) 前颜不同 : 左 魔方右转 下右上(角藏前 棱放后)

## F2L 白在上
白上棱下(紧挨) 上左下右 * 3

白上棱下(保存标态) 上右下左

白上棱不紧挨 棱块与魔方中心块颜色对齐 向要去的槽后面走 角块去接

白上棱左(紧挨) 前颜相同 : 上左下右右 上左下右 上左下

白上棱后(紧挨) 右颜相同 : 顺 左上右下 逆 上右下

白上棱左(紧挨) 前颜不同 : 魔方右转 下右右上左(棱藏前 角放左后方) -> 逆右顺标态

白上棱后(紧挨) 右颜不同 : 上右右下右(棱藏后 角放左下) -> 上左下标态
